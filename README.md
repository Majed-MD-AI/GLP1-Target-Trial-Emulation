# GLP1 Target Trial Emulation

A reproducible real-world evidence project demonstrating how a target trial can be emulated using synthetic longitudinal healthcare data.

## Project Aim

This project evaluates the effect of preconception GLP-1 receptor agonist discontinuation strategies on pregnancy outcomes using a target trial emulation framework.

The project is designed as a methodological portfolio project connecting:

- Target Trial Emulation
- External Control Arms
- Real-World Evidence (RWE)
- OMOP-style cohort design
- EHDS-compatible evidence generation concepts
- EU Health Technology Assessment (HTA)

## Data

The analysis uses synthetic longitudinal patient-level data created for educational and methodological demonstration purposes.

No real patient data are used.

## Planned Workflow

1. Specify the hypothetical target trial
2. Generate a synthetic longitudinal cohort
3. Apply eligibility criteria and define time zero
4. Define treatment strategies
5. Assess baseline confounding
6. Estimate propensity scores
7. Apply inverse probability weighting
8. Estimate treatment effects
9. Perform sensitivity analyses
10. Present HTA-relevant evidence outputs
